# 未入金注文の自動キャンセル期限（Issue #46）

## 目的

Issue #46「未入金注文の自動キャンセルまでの日数を、管理者が管理画面から変更できるようにする（デフォルト7日）」について、Shopifyネイティブの管理画面設定で実現できないかを確認する。Issue本文ではShopify Flowが候補として挙げられているが、Flowより低コストな手段がないかを先に確認する。

## 確認した場所

開発ストア（`rice-market-dev.myshopify.com`）の管理画面で、未入金注文の自動キャンセルに関係しそうな設定を3箇所確認した。

1. **設定 > チェックアウト**（`/settings/checkout`）
   チェックアウト離脱時の「決済未完了の通知メール」送信タイミング（1時間後/6時間後/10時間後/24時間後）はあるが、これはメール送信の設定であり、注文のキャンセルとは無関係。ページ全体を確認したが、未入金注文の自動キャンセルに関する項目はない。

2. **設定 > 一般 > 注文処理**（`/settings/general`）
   「注文処理」セクションには、支払い済みになった後のフルフィルメント自動化（自動/手動）と、フルフィルメント・支払いともに完了した後の自動アーカイブ設定しかない。**未入金のまま一定期間経過した注文を自動キャンセルする項目はない。**

3. **設定 > 決済 > 手動の決済方法**（`/settings/payments/manual-payment-methods`）
   代引き・銀行振込（このストアで既に設定済み）の編集画面には「追加情報」「決済手順」の2つのテキストフィールドしかなく、期限日数を指定する項目はない。

Web検索でも同様の結論（Shopify標準にはこの機能はなく、Shopify Flowまたはサードパーティアプリでの実装が必要）が複数のShopifyコミュニティ投稿で確認できた。

## 結論

**Shopify管理画面には「未入金注文を指定日数後に自動キャンセルする」ネイティブ設定は存在しない。** 実現にはShopify Flow（スケジュールトリガー + 未入金注文の検索 + キャンセルアクション）か、サードパーティアプリが必要。

Flowは[serverless-options.md](./serverless-options.md)で確認済みの通り、本番Basicプランでは使えるが、このストアのプラン（`Basic App Development`）では開けない。したがって **#46はDevストアでは実装・検証できず、#8（注文と派遣元の紐付け、Flow依存）と同じ制約に当たる。**

カスタムアプリ側（`apps/shopify-app/`）にスケジュール実行ジョブを持たせる手段もあるが、これは常時稼働するサーバーが必要になり、[serverless-options.md](./serverless-options.md)で決定した構成B（サーバー不要）の前提と矛盾するため採用しない。

## 本番実装での見込み

- 本番Basicプラン契約後（Issue #19 移管後）にFlowで「スケジュールトリガー（毎日）→ 未入金かつ作成からN日経過した注文を検索 → キャンセル」を組めるか確認する
- 管理者が日数を管理画面から変更できるようにする要件は、Flowのトリガー条件に使う数値をどこに持たせるか（Flow内に直書きか、メタフィールド等で外出しするか）次第。これも本番プランでの検証が必要
- nice to haveであり、登録・購入ゲートという中核機能には影響しない（[serverless-options.md](./serverless-options.md)の構成B決定を参照）
