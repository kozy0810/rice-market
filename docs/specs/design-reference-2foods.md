# デザイン参考: 2foods.jp（Issue #33）

Issue #33「UIデザイン・フォントの参考として2foods.jpを調査する」の調査結果。実際にサイトを操作し、DevToolsでCSS変数・フォント指定を確認した。

## 前提: 2foods.jp自体がShopifyで構築されている

`window.Shopify`オブジェクトが存在し、テーマ名は `2foods-shopify/provisional-master`。Dawnそのままではなくカスタムテーマだが、**同じプラットフォーム上での実現例として直接参考にできる**。CSS変数の命名（`--heading-font-family`、`--button-background`など）もDawn系の構造に近く、`rice-market-storefront`（Dawnベース）に同様の変更を加えるハードルは低いと判断できる。

## フォント

| 用途 | フォント | 出典元 |
|---|---|---|
| 見出し・本文（英数字） | Inter | Google Fonts |
| 見出し・本文（日本語） | Noto Sans JP | Google Fonts |
| 一部要素 | Lato | Google Fonts |

すべてGoogle Fontsで配布されているフォントで、ライセンスは[SIL Open Font License 1.1](https://openfontlicense.org/)。商用利用・改変・再配布が無償で許可されており、ライセンス上の懸念はない。

**Shopifyテーマでの利用方法**: Google Fontsは`@font-face`でセルフホスト（フォントファイルをテーマの`assets/`に配置）するか、Google Fonts CDN経由で読み込める。Dawn系テーマの「タイポグラフィー」設定はカスタムフォントのアップロードに対応しているため、Inter・Noto Sans JPのWoff2ファイルを`assets/`に追加し、`settings_schema.json`のフォント選択肢に加えれば同様の見た目を再現できる。**技術的な障壁もライセンス上の障壁もない。**

## 配色

ベースは白背景+黒系文字の抑えたパレットで、装飾色はセクション単位で使う設計。

| 用途 | 値 |
|---|---|
| 背景 | `#ffffff` |
| 見出し・本文文字 | `#212121` |
| 補助文字（価格・キャプション等） | `#6a6a6a` |
| ボタン背景 | `#212121`（黒） |
| ボタン文字 | `#ffffff` |
| 罫線・区切り線 | `#dedede` 〜 `#e9e9e9` |

トップページのヒーローセクションのみ、パステル紫・ミントのストライプ背景と、雲形（スカラップ）の白カードを組み合わせた装飾を使っている。**グローバルなブランドカラーではなく、キャンペーン訴求セクション限定の装飾**という位置づけに見える。米ECサイトの基調としては、この「ベースは黒白の抑えたトーン、要所だけ差し色」という考え方が参考になる。

## レイアウト・UI

### ヘッダー
- ロゴは太字の小文字ロゴタイプ（`2foods`）のみ、画像ロゴではなくテキストロゴ
- グローバルナビはドロップダウン付きのテキストリンク（2foodsについて／オンラインで買う／店舗／レシピ／magazine／法人向け卸販売）
- 右上に検索・お気に入り・アカウント・カートのアイコンを横並びで配置

### トップページ
- フルブリードの大きな写真セクションを縦に積む構成（商品写真・世界観訴求写真を交互に）
- 余白を広くとり、1セクション1メッセージに絞っている
- キャンペーンバナーのみ装飾的な配色・形状を使い、それ以外は写真とタイポグラフィで見せる

### 商品一覧ページ（`/collections/all`）
- シンプルな3カラムグリッド
- 商品写真は薄いグレーのグラデーション背景の上に配置（商品パッケージが際立つ）
- 商品名は太字、価格はその下に軽いウェイトで表示

### 商品詳細ページ
- 冒頭にパンくずリスト（`2foods › 商品名`）
- 商品写真はフルワイドで大きく、余白の多い薄グレー背景の上に配置
- 本文は「特長」という中見出しの下に「おいしさの特長」「ヘルシーな特長」「アレルギー・栄養成分情報」のように**サブ見出し＋箇条書き**で構成。長文の説明文ではなく、スキャンして読める短い箇条書きが徹底されている

### フッター
- 「オンラインで買う」「店舗一覧」「お客様サポート」「お知らせ」「会員の方へ」の5カラム構成、各カラムに見出し＋リンクリスト
- SNSアイコンは円形の枠線アイコン
- ニュースレター登録は横長の入力欄＋円形の送信ボタン（矢印アイコン）

## rice-marketへの示唆

- **配色**: 白背景＋黒系文字＋黒ボタンの抑えたベースは、米という商品の落ち着いた印象と相性が良い。装飾色を使うなら「派遣元ごとの登録ページ」のような特定セクションに限定し、グローバルな配色は変えない、という2foodsの使い分けが参考になる
- **フォント**: Inter + Noto Sans JPの組み合わせはライセンス・実装コストの両面で障壁がなく、そのまま踏襲できる候補
- **商品詳細ページの構成**（見出し＋箇条書きでスキャンしやすくする）は、技能実習生が母語でない日本語を読む前提のサイトにおいて特に有効。長文の説明文より箇条書きを優先する方針を採用する価値がある
- **商品一覧のグリッド**（薄いグレー背景＋シンプルな3カラム）は、コシヒカリ3商品（5kg/10kg/30kg）を並べる現行構成とそのまま相性が良い

## 実装（2026-10-08、Issue #64）: フッターの構造再現とヘッダーのロゴ間隔調整

2foods.jpのフッター・ヘッダーを参考に、rice-marketで実際に持っているコンテンツの範囲で構造だけを再現した。5カラム構成への完全準拠はせず、存在しないページ（店舗一覧・レシピ・法人向け卸販売相当）へのダミーリンクは作らない方針とした（判断の経緯はIssue #64参照）。

### フッター

`themes/storefront/sections/footer-group.json`に`link_list`ブロックを1つ追加し、ニュースレター登録欄を有効化した。

- **「ショップ」カラム**: 見出し＋リンクリスト（ホーム／商品一覧／お問い合わせ）。参照先はテーマの`footer`メニュー（コンテンツ > メニュー）
- **ニュースレター登録欄**: `newsletter_enable: true`に変更。見出しは「最新情報をメールで受け取る」
- **ポリシーリンク**: Dawn標準機能（`show_policy: true`、既存設定のまま）。フッター下部に`shop.policies`から自動表示される。設定 > ポリシー で公開済みなのは「返品・返金ポリシー」「プライバシーポリシー」「特定商取引法に基づく表記」の3件（「利用規約」「配送ポリシー」「連絡先情報」「購入オプションのキャンセルポリシー」は未設定のまま、今回のスコープ外）
- **SNSアイコン**: 非表示のまま。`settings.social_*_link`が全て空だとDawnが自動的に非表示にする標準挙動に従っている（実アカウントがないため今回はリンクを設定していない）。アカウントができたら`settings_data.json`の`social_instagram_link`等にURLを設定すれば表示される

**管理画面側の状態（Git管理外）**: テーマの`footer`メニュー（ハンドル`footer`）の中身を、デフォルトで残っていた「Search」項目（Dawnの初期データの名残、不要）から「ホーム（ホームページ）／商品一覧（すべてのコレクション）／お問い合わせ（Contactページ）」の3項目に差し替えた。開発ストアを作り直す場合は、コンテンツ > メニュー で`footer`ハンドルのメニューに同じ3項目を再設定する必要がある。

### ヘッダー（ロゴとナビメニューの間隔）

`.header__heading-logo`に`margin-right`を足す方式は、ロゴのgridトラック（`auto`幅）自体を広げてヘッダー全体の幅が変わってしまう（ロゴ拡大時の回帰と同じ原因）ため採用しなかった。代わりに`.header--middle-left`の`column-gap`を`2rem`→`3.5rem`に広げ、gapで間隔を取る方式にした。gapはgridトラックの外側にあるため、ヘッダー全体の幅やロゴ自体のレイアウト占有幅には影響しない。
