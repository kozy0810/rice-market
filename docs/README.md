# docs/

| ディレクトリ | 役割 |
| --- | --- |
| `human/` | 人間向けの要件定義・進捗のまとめ |
| `specs/` | 機能ごとの仕様書 |
| `research/` | Shopifyの仕様調査結果（トピックごとに1ファイル。「できる/できないか」の一次情報） |

`human/dev-store-review.html` は友人（ストアの引き継ぎ先）に渡すための引き継ぎレビュー用ドキュメント。Artifactとして公開して共有するため、Markdownではなく公開するHTMLそのものをリポジトリに置いている（公開物と内容がズレないようにするため）。更新したら同じArtifactのURLへ再公開する。

`shopify-verification-log.md` は上記のディレクトリ分類に含めず、`docs/`直下に置いている。`research/`配下の索引と、要件ごとの可否判定のまとめを持つ運用ドキュメント。Shopifyの仕様に不明点があれば、まずこのファイルから該当する`research/`のファイルをたどる。
